# Security Policy

## Supported versions

Security fixes are currently considered for the latest `main` branch and the latest published release.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability. Email **diwaskhatri@proton.me** with:

- a short description and impact;
- affected version/module;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation.

Please allow reasonable time for investigation before public disclosure. Do not include real credentials, private network details or user data in a report.

## Scope

The project is designed for local networks. The controller protocol is not intended to be exposed to the public internet. Reports involving unintended network exposure, authentication bypasses, credential leakage or unsafe handling of sensitive data are especially welcome.
